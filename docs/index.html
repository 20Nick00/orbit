Anything with a balance or a cash flow. The app infers the type and places it on the ledger.

How it adapts

Type inference
Checking, savings, brokerage, 401(k), HSA, card, loan, mortgage, crypto and property are detected from the institution and account metadata. Override in one click.
Column mapping
CSV and OFX imports map date, amount, memo and balance automatically; unknown layouts get a one-time mapping you can save as a rule.
Manual assets
Home, vehicle, private holdings, collectibles. Enter a value and an optional estimate source; history starts today.
Your data, your machine
Self-hosted. SQLite file you can copy. Export everything as CSV at any time.

Almanac

The yearly record. One row per year, kept forever: what you had, what came in, what went out, what you kept.
